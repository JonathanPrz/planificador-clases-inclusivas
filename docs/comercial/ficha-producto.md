# Ficha De Producto Comercial

## Nombre De Trabajo

**Aula Clara**

Nombre temporal para una solución web independiente orientada a instituciones educativas.

## Propuesta De Valor

Herramienta web para que equipos educativos transformen orientaciones de inclusión, accesibilidad y apoyo docente en planes claros, documentables y fáciles de compartir.

## Público Objetivo

- colegios;
- institutos profesionales;
- centros de formación técnica;
- universidades;
- fundaciones educativas;
- equipos PIE, inclusión, bienestar o apoyo académico.

## Problema Que Resuelve

Muchas instituciones cuentan con orientaciones, protocolos o criterios de apoyo, pero estos suelen estar dispersos en documentos extensos. Esto dificulta que docentes y equipos traduzcan la información en acciones concretas para la clase.

## Funcionalidades Base

- base DUA para planificar clases accesibles;
- consulta de apoyos por condición o barrera;
- matriz funcional inspirada en CIF;
- priorización visual de apoyos;
- recomendaciones editables;
- generación de PDF;
- seguimiento posterior;
- métricas anónimas de uso;
- referencias y recursos públicos.

## Diferenciador

La solución combina criterio pedagógico, inclusión, accesibilidad y desarrollo web en un flujo simple para docentes. No se presenta como diagnóstico ni reemplaza a equipos profesionales; ayuda a ordenar decisiones y documentar apoyos.

## Versión Comercial Mínima

La primera versión comercial debe incluir:

- identidad visual propia;
- catálogo genérico de recomendaciones;
- referencias públicas;
- PDF sin marca institucional ajena;
- formulario de retroalimentación propio;
- métricas propias o desactivables;
- documentación de privacidad;
- manual breve de uso.

## Lo Que No Debe Prometer

- diagnóstico clínico;
- cumplimiento automático de obligaciones legales;
- reemplazo de equipos de inclusión;
- recomendaciones infalibles;
- almacenamiento de fichas o antecedentes sensibles sin infraestructura y consentimiento adecuados.

## Modalidades De Venta Posibles

- implementación por institución;
- licencia anual;
- personalización por sede o programa;
- mantención mensual;
- capacitación docente;
- desarrollo de módulos a medida;
- auditoría y mejora de materiales accesibles.

## Mensaje Comercial Inicial

> Soluciones web para que instituciones educativas conviertan criterios de inclusión y accesibilidad en herramientas simples, aplicables y documentables para sus equipos docentes.
