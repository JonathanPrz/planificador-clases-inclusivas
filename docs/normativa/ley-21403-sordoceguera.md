# Ley 21.403 — Sordoceguera como discapacidad única

| Dato | Valor |
| --- | --- |
| Título oficial | Reconoce la sordoceguera como discapacidad única y promueve la plena inclusión social de las personas sordociegas |
| Organismo | Ministerio de Desarrollo Social y Familia |
| Publicación | Diario Oficial núm. 43.142, 3 de enero de 2022 · CVE 2066602 |
| Texto publicado | [Edición del Diario Oficial](https://www.diariooficial.interior.gob.cl/edicionelectronica/index.php?date=03-01-2022&edition=43142) |
| Texto vigente | [BCN Ley Chile](https://www.bcn.cl/leychile/navegar?idNorma=1170743) |

> Extracto de trabajo con resúmenes propios. Para citar, usar el texto publicado o el vigente.

## Qué establece

Modifica la Ley 20.422 para reconocer la sordoceguera como una discapacidad única, no como la suma de una discapacidad auditiva y una visual. Define a la persona sordociega y al guía intérprete.

## Artículos que usa el planificador

| Artículo (Ley 20.422) | Contenido (resumen) | Uso en el planificador |
| --- | --- | --- |
| Art. 8 ter | El Estado promoverá la formación de guías intérpretes. | Contexto para coordinar apoyos con guía intérprete. |
| Art. 26 ter | Reconoce como sistemas de comunicación oficiales la dactilología, el braille, las técnicas de orientación y movilidad y otros sistemas alternativos. La persona sordociega elige el sistema que usa. | El planificador trata la sordoceguera como condición propia. Los apoyos deben respetar el sistema de comunicación que elija el estudiante. |
