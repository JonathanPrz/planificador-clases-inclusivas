1. Descripción del Software

1.1. ¿Qué es?

El Planificador Inclusivo UIE es una aplicación web progresiva (PWA) que permite a cualquier docente de Duoc UC planificar clases inclusivas en minutos. Integra en una sola interfaz:

  • Checklist completo de Diseño Universal para el Aprendizaje (DUA)
  • Gestor de adecuaciones curriculares para 8 perfiles de discapacidad
  • Fusión inteligente de recomendaciones para múltiples estudiantes
  • Generación de informes PDF profesionales con respaldo institucional
  • Módulos de apoyo (crisis, accesibilidad digital, lectura fácil, inserción laboral, vocabulario inclusivo)
  • Funcionamiento offline, modo oscuro y diseño responsive

4. Términos y Condiciones

4.1. Derechos de uso

  • Licencia perpetua para las modalidades B, C y D: Duoc UC puede usar el software indefinidamente una vez adquirido.
  • Uso ilimitado en todas las sedes y por todos los docentes.
  • No exclusividad: El desarrollador puede comercializar el software a otras instituciones.
  • Código fuente: Se entrega el código fuente completo para auditoría y transparencia, pero los derechos de autor pertenecen al desarrollador.

4.2. Soporte y actualizaciones

  • El soporte incluye resolución de errores, dudas de uso y asistencia técnica menor.
  • Las actualizaciones normativas cubren cambios en leyes, decretos y regulaciones aplicables.
  • Las mejoras mayores (nuevos módulos o funcionalidades sustanciales) se cotizan por separado, salvo que estén incluidas en un plan de mantención vigente.

4.3. Exclusiones

  • No incluye hosting ni infraestructura (GitHub Pages es gratuito, pero si Duoc UC prefiere un servidor institucional, corre por su cuenta).
  • No incluye creación de contenido pedagógico (guias, rúbricas, evaluaciones).
  • No incluye integración con sistemas existentes (Blackboard, PeopleSoft, etc.) a menos que se acuerde por separado.

4.4. Confidencialidad

El desarrollador se compromete a no divulgar información institucional sensible a la que pudiera tener acceso durante la implementación y soporte.

  1. Reunión de demostración (30 min): Recorrido guiado por todas las funcionalidades, resolviendo dudas en vivo.

  4. Implementación: Despliegue, personalización de marca y capacitación (1-2 semanas).
