## Cómo generar PDF

Los archivos `.html` están diseñados para imprimirse como PDF profesional:

1. Abrir el `.html` en Chrome o Edge
2. Ctrl+P (Imprimir)
3. Seleccionar "Guardar como PDF"
4. Desmarcar "Encabezados y pies de página"
5. Imprimir

## Estrategia de presentación

1. **Primero**: Presentación ejecutiva (slides) — mostrar el problema, la solución y el ROI
2. **Segundo**: Demo en vivo de la herramienta
3. **Tercero**: Entregar propuesta de licenciamiento impresa
4. **Cuarto**: Informe técnico-valórico como respaldo para la negociación de horas
