# Ficha Técnica De Autoría

## Proyecto

**Planificador Inclusivo UIE**

Herramienta web de apoyo docente para planificar clases inclusivas, aplicar principios de Diseño Universal para el Aprendizaje (DUA), orientar adecuaciones curriculares de acceso y generar planes de apoyo docente.

## Autoría Del Prototipo

**Diseño y desarrollo del prototipo:** Jonathan Pérez  
**Rol institucional:** Coordinación de Inclusión, Duoc UC Campus Arauco  
**Naturaleza del desarrollo:** iniciativa de innovación pedagógica orientada a mejorar la gestión docente de apoyos inclusivos.

## Propósito

El prototipo busca entregar una herramienta práctica para que docentes y equipos de inclusión puedan:

- identificar barreras de acceso y participación;
- revisar orientaciones DUA;
- consultar apoyos y adecuaciones curriculares por condición;
- ajustar perfiles de apoyo mediante matriz CIF;
- generar un plan de apoyo docente en PDF;
- revisar recursos complementarios y referencias institucionales.

## Componentes Principales

- Interfaz web estática en HTML, CSS y JavaScript.
- Catálogo de recomendaciones de apoyo pedagógico y adecuaciones curriculares.
- Matriz CIF para precisar necesidades de apoyo.
- Priorización visual de recomendaciones mediante semáforo.
- Generación de PDF para coordinación docente.
- Modo claro/oscuro.
- Métricas anónimas de uso mediante Microsoft Clarity y contador público de visitas/corazones.
- Documentación técnica y de usuario.

## Estado Actual

El prototipo se encuentra operativo como aplicación web estática, sin backend propio ni sistema de autenticación. La información ingresada por el usuario se procesa en el navegador para generar orientaciones y documentos, sin almacenar datos personales de estudiantes en servidor.

## Consideraciones Para Institucionalización

Antes de adoptar la herramienta como recurso institucional, se recomienda definir:

- reconocimiento formal de la autoría del prototipo;
- dominio, hosting y repositorio institucional;
- responsable funcional de contenidos y actualizaciones;
- responsable técnico de publicación y mantención;
- revisión institucional de privacidad, métricas y uso de servicios externos;
- alcance de uso: campus, sede, área o nivel institucional;
- condiciones de soporte, mejora continua y mantención.
